Quizzler: A desktop true/false quiz app built with Python and Tkinter. 
It pulls 10 fresh trivia questions from the Open Trivia Database API each time it runs, 
shows them one at a time, and flashes the canvas green or red to tell you instantly whether your answer was right, 
while keeping a running score. The project uses an object-oriented design with separate classes for the question data (Question), 
the quiz logic (QuizBrain), and the user interface (QuizInterface). Built with requests, tkinter, and html.
